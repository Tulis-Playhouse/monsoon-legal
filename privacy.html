Privacy Policy

Last updated: 14 November 2026

The Morfo publishing tool is a private tool run by one studio on its own computer. It uses YouTube API Services only on the studio's own YouTube channels. Nobody else signs in.

YouTube API Services

This tool uses YouTube API Services. By using it, the studio is bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. Access granted to this tool can be reviewed and revoked at any time on the Google security settings page.

What we access

With the studio owner's own Google sign-in we use the scopes youtube.upload, youtube.readonly, youtube.force-ssl and yt-analytics.readonly to: upload our own videos, thumbnails and captions; set channel branding and playlists on our own channels; check the status of our own uploads; and read aggregate reports (views, retention, click-through) for our own channels.

What we store

Our own video ids, upload status and channel-level analytics numbers, and OAuth tokens, kept in local files on the studio owner's computer. We do not collect, store, sell or share personal data about viewers or any other YouTube user. Nothing is passed to third parties. Analytics data is refreshed or deleted according to the YouTube API Services Developer Policies.

Deleting data and revoking access

The owner can delete the local files at any time and revoke the tool's access in Google security settings, which makes any stored tokens unusable. Questions or deletion requests: tulisplayhouse@gmail.com.
